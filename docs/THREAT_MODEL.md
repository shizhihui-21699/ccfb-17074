# 威胁模型与安全论证

## 1. 资产与信任边界

**受保护资产**

- 机主的通讯录关系（谁和谁是熟人）——属于隐私，不能在广播中泄露；
- 设备长期身份（Ed25519 公钥）——不能被被动观察者跨地点追踪；
- 文件内容与 Wi-Fi Direct 凭据——需要保密性与完整性；
- 接收决策的正确性——不能被伪造的设备名/文件名误导。

**信任边界**

- BLE 广播信道与 Wi-Fi Direct 链路均视为**攻击者可控**：可被动监听、
  重放、篡改、注入；
- 设备名、文件名、声明 MIME 等**自报字段一律不可信**；
- 仅有的带外信任锚点：① 面对面扫码配对（物理在场）；
  ② 同账号设备由账号服务经 E2EE 通道一次性预置。

## 2. 攻击者能力与对应防护

| 攻击 | 能力 | 防护机制 | 验证测试 |
|------|------|---------|---------|
| 设备名仿冒 | 任意自报设备名 | 信任只由身份密钥+PSK 决定，名字仅作展示 | `地铁攻击者改设备名无法通过身份验证` |
| 伪造熟人身份 | 无配对 PSK | 信封 AEAD 解密必然失败；无 PSK 只能走陌生人通道 | `PSK 不匹配时信封解密失败` |
| 窃取身份冒充 | 拿到别人公钥无私钥 | 信封内含身份私钥对转录的 Ed25519 签名 | `攻击者公钥与目录身份不一致时握手失败` |
| 握手中间人 | 替换临时公钥 | 身份签名/AEAD 绑定握手转录，篡改即验签失败 | `中间人替换临时公钥导致身份验签失败` |
| 恶意安装包 | APK 改名 .pdf | 魔数嗅探真实类型 + ZIP 内 APK 特征，陌生人拦截 | `陌生人发送 APK 被直接拦截` |
| 不雅图片社工 | 陌生人强推图片 | 陌生人图片仅模糊预览、隔离、需手动确认 | `陌生人发图片仅模糊预览且隔离存放` |
| 流量重放 | 录制并重发加密帧 | nonce 单调计数器，重放帧计数不匹配被拒 | `重放旧帧因 nonce 计数推进被拒绝` |
| 帧篡改 | 翻转密文比特 | ChaCha20-Poly1305 完整性标签校验 | `篡改通道消息导致完整性校验失败` |
| 文件篡改 | 传输中改内容 | 清单 SHA-256 与流式落盘哈希比对 | `文件内容被篡改导致哈希校验失败` |
| 跨地点追踪 | 长期监听广播 | 临时 X25519 每周期轮换，标签随周期全变，广播无稳定 ID | `临时密钥轮换后标签全部变化` |
| 广播反推联系人 | 拿到 Bloom 过滤器 | 标签由 PSK 派生，无 PSK 无法生成/反推 | `广播材料不包含身份公钥或显示名` |

## 3. 三档信任的安全语义

| 层级 | 身份依据 | 可执行文件 | 图片预览 | 落盘 |
|------|---------|-----------|---------|------|
| SAME_ACCOUNT | 账号主密钥派生 PSK + 身份验签 | 允许，风险提示 | 正常 | 正常目录 |
| CONTACT | 扫码配对 PSK + 身份验签 | 允许，二次确认，隔离 | 正常 | 可执行文件先隔离 |
| STRANGER | 无（仅临时 ECDH，无认证） | **一律拦截** | 模糊 | 仅隔离区 |

关键不变量：**`STRANGER` 通道永远不可能产生可执行文件落盘，也永远
不会显示"已认证"徽章或通讯录中的熟人名字。** 自报设备名在该层级只生成
随机临时别名。

## 4. 已知局限与残留风险（诚实声明）

1. **陌生人临时通道无 MITM 防护**：没有共享秘密就无法认证，这是密码学
   基本约束。该通道因此被显式标记 `authenticated=false` 并施加最严策略，
   把"无认证"的后果限制在不可执行、模糊、隔离范围内，而非伪装成可信。
2. **Bloom 过滤器存在误报**：设计误报率 1%，可能让接收方对陌生人产生一次
   候选命中；但后续握手信封验签会彻底排除误报，不会因此提升信任层级。
3. **配对依赖人工核对 SAS**：若用户在两台设备 SAS 不一致时仍点确认，
   会接受中间人配对。6 位 SAS 把盲目攻击成功率压到百万分之一，但无法
   防住完全不看屏幕的用户。
4. **终端安全不在本方案范围**：若设备已被 root/植入恶意系统组件，
   Keystore 与 UI 提示本身可能被绕过；本方案假设系统与应用运行环境可信。
5. **同账号预置需要一次联网**：账号设备清单的首次下发发生在有网时刻，
   之后近场发现/握手/传输全程离线；这是"完全离线近场验证"与"账号体系"
   之间的合理边界。
